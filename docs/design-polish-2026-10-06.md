# Полировка Gate One LTD — 6 октября 2026

Обновлено 11 октября 2026. Ветка `design/multilingual-polish` поверх `preview/multilingual-audit` прошла локальную проверку и готова к просмотру владельцем в PR №2. Базовый коммит — `091889e8a683df4cd632adce98e22433f6eaacef`. Production не обновлён.

## Изменения

- Заголовки четырёх разделов получают естественные переносы во всех пяти локалях.
- У крупных заголовков уменьшено сжатие букв; для арабского сохранены отдельные правила набора.
- Мобильные размеры заголовков и первого экрана адаптируются к окну; абзацы используют text-wrap: pretty с обычным переносом в качестве fallback.
- Декоративная надпись SEA / скрыта. Функциональные разделители и индикаторы фокуса сохранены.
- В EN/RU/UK/DE/AR сокращены повторяющиеся описания услуг и принципов без изменения фактов, слогана, тоннажа, SEO и предупреждений об иллюстрациях.
- Клавиатурное открытие мобильного меню переводит фокус на первую ссылку.
- Доступные имена выбора языка и изображения включают видимые подписи.
- Добавлена навигация без JavaScript через noscript на экранах до 1100 px.
- На экранах до 380 px характеристики судна расположены в одну колонку: длинные украинские и немецкие слова сохраняются целиком.
- Добавлены два Node-теста и три E2E-сценария для регрессий. Снимки страниц дожидаются загрузки иллюстрации судна.

Воспроизведён дефект: Enter открывает меню, следующий Tab пропускает его ссылки и попадает на CTA основного содержимого. Проверка кода также обнаружила потерю выбранного языка в доступном имени и отсутствие mobile fallback без JavaScript.

Прочитаны все пять словарей. Просмотрены первые экраны DE/AR на 390 × 844 и содержимое EN. Полный браузерный проход RU и проверка экранным диктором не выполнены. Языковая редактура моделью не является проверкой носителями.

## Среда выполнения Codex

Команды внутри защитной среды блокировались ошибкой `helper_unknown_error: setup refresh had errors`. Проверка с явным разрешением на запуск вне неё прошла, после чего установка, сборка и тесты выполнены тем же способом. Общие настройки защиты не изменялись. Встроенное управление браузером Codex также возвращало эту ошибку; браузерная проверка выполнена тестами проекта через Microsoft Edge.

Git потребовал доверия к папке, созданной служебным пользователем. Использован параметр `-c safe.directory=D:/AI/projects/seagateone` только в конкретных командах. Системный pnpm 10.28.0 зациклился при выборе версии; зависимости установлены уже имеющимся pnpm 11.19.0 напрямую. Кеш и временные файлы размещены в игнорируемой папке `.browser-cache/` проекта.

6 октября обновление отчёта остановилось из-за лимита сервиса автоматической проверки разрешений. Исходники и результаты тестов сохранились; работа возобновлена 11 октября.

```powershell
pnpm install --frozen-lockfile

pnpm build
pnpm start --hostname 127.0.0.1 --port 3001
```

```powershell
$env:TEST_BASE_URL='http://127.0.0.1:3001'
pnpm test:e2e
```
