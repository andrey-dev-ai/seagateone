## Ограничения

Подтверждённых email, телефона и адреса в публичной конфигурации нет. Их нельзя выдумывать. Отдельно от проверки кода потребуется подтверждение владельцем переводов, данных о компании и контактов. Изображения остаются иллюстративными, а не реальными фотографиями судна.

## Подтверждённый порядок работы

1. Сохранить исходный шаблон и изображения без удаления старых деплоев.
2. Подготовить серверные языковые страницы, переводы и RTL с сохранением существующего морского визуального стиля.
3. Исправить найденные дефекты и зависимости; добавить регрессионные тесты.
4. Проверить production-сборку, типы, браузерные сценарии, переполнение и доступность; записать фактические результаты.
5. Выгрузить код в GitHub и получить preview. Production не обновлять до одобрения preview пользователем.

Проверены Next.js 16.3.6, React 19, Node 24.12.0, pnpm 11.19.0. Production-домен не изменялся.

| Категория | Результат |
| --- | --- |
| Баги | Исправлены URL/язык/история, перевод aria-label, адрес без телефона и пустые tel: |
| Безопасность | HIGH CONFIDENCE эксплуатируемых уязвимостей кода не выявлено; pnpm audit — 0 известных предупреждений после обновления next и удаления CLI |
| Качество | typecheck и production build прошли, ignoreBuildErrors убран |

| Адаптивность | 5 языков × 320/375/768/1024/1440/1920px: горизонтального переполнения не обнаружено |
| Доступность | axe с wcag2a/wcag2aa/wcag21aa/wcag22aa: 0 нарушений в проверенных состояниях пяти мобильных страниц; проверены меню, Escape и восстановление фокуса диалога |
| Тесты | 6 Node-тестов и 11 браузерных сценариев прошли на финальной production-сборке, включая логотип, 404 и режим без JavaScript |

Дизайн улучшен точечно: восстановлен GateSans, увеличены мелкие подписи и области нажатия, усилен фон под текстом hero, добавлены логические RTL-отступы, баланс заголовков и меню для планшетов. Не добавлены неподтверждённые услуги, фотографии, адреса или заявления.

Остаётся: одобрение переводов владельцем/носителями, подтверждённые контакты, онлайн-preview с доступом к Vercel-команде, ручная проверка экранным диктором и на реальных Safari/Firefox/iOS/Android. Узкий viewport проверяет reflow, но не является отдельной проверкой всех режимов браузерного zoom. Не выдаём это за полное соответствие WCAG.

Строгий CSP не включён без отдельной проверки nonce/hash и совместимости Next.js; отсутствующий CSP сам по себе не представлен как доказанная уязвимость. Добавлены nosniff, DENY framing, referrer и permissions policies. Входов пользователей/форм/API с бизнес-данными в текущем сайте нет.

Локальное лабораторное измерение финальной версии с логотипом, localhost + Edge без ограничения сети/CPU: LCP 272 ms, CLS 0.00132, передано около 603 kB на первой desktop-странице. Это единичное измерение, не оценка реальных посетителей и не обещание аналогичной скорости на телефонах. INP в полевых условиях не измерялся. WebP использует отдельный мобильный hero, нижние изображения lazy, шрифт локальный, размеры картинок заданы; CSS собирается Next.js.

Скриншоты генерируются браузерным тестом в docs/screenshots/ (не коммитятся). Финальный онлайн-preview и повторная проверка на Vercel ещё требуются перед выпуском.

Дополнительная проверка обнаружила сброс cookie языка на 404: скрипт записывал en из общего layout. Воспроизведено тестом (ожидалось de, получено en); исправлено проверкой наличия настоящего интерфейса сайта до записи cookie. Регрессионный тест прошёл.

По дополнительному запросу владельца старый знак заменён на монограмму G1: шапка, подвал, SVG/PNG favicon, Apple touch icon. Растровые мастеры подготовлены по предоставленному референсу; лёгкий WebP используется в интерфейсе, а не тяжёлый мастер. Бренд не зеркалится в арабской версии. Официальный векторный оригинал не был предоставлен.
